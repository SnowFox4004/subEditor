# srtEditor

纯浏览器端的字幕编辑器。**零后端**，所有解析、编辑、替换、导出都在用户自己的浏览器里完成，文件不上传任何服务器。

## 线上体验

**[https://srteditor-azw.pages.dev](https://srteditor-azw.pages.dev)** —— 打开即用，无需注册与安装。

## 使用方式

把一个或多个字幕文件直接拖进页面，或点「打开字幕」选择文件即可开始，一个文件一个标签页。

首次打开后可安装为桌面应用（PWA），断网后仍能打开使用；工作区会自动保存，刷新或意外关闭后可原样恢复。

## 功能

### 多文件与多标签页

- 一次拖入多个字幕，一文件一标签
- 标签可拖拽重排、中键关闭；有未保存修改时显示黄点，关闭会二次确认
- 每个标签页有独立的撤销历史（100 步）
- 批量替换可以跨全部标签页执行

### 可视化编辑

- **表格视图**：逐条行内编辑，虚拟滚动（1 万条不卡）
- **表格列可调**：直接拖动表头分隔线调整列宽，双击分隔线恢复该列默认宽度；工具栏「列设置」可勾选显示哪些列、精确指定像素宽度。列宽与显隐会记住，刷新后保留。至少保留一列
- **时间码**：`HH:MM:SS,mmm` 分段输入，`↑`/`↓` 按字段步进，输入 `:` 自动跳到下一段
- **时间轴视图**：横向轨道，拖块体平移、拖两端调整起止、多选整体平移；吸附到相邻条目首尾与播放头；重叠条目描红；`Ctrl/⌘ + 滚轮` 缩放，可一键适应宽度
- **媒体预览**：拖入本地视频/音频后，媒体区位于**编辑区上方并占满整行宽度**，视频按原始比例居中显示；拖动两者之间的分隔条可随时调整高度比例（双击分隔条恢复默认）。字幕按时间精确叠加在画面上（叠加层尺寸按视频实际显示区域计算，黑边不会让字幕跑偏）；双击表格条目跳转到该时间点；播放时表格自动高亮并跟随滚动；空格键播放/暂停
- 条目操作：新增 / 拆分（优先按换行切，否则在标点处切）/ 与下一条合并 / 复制 / 锁定 / 删除

### 批量替换

- 多规则叠加，按顺序依次应用
- 模式：字面量 / 正则（支持 `$1` 反向引用）；可选区分大小写、整词匹配
- 作用目标：正文 / 说话人 / 两者
- **字符级 diff 预览**：先算不改，被改动的字符用底色标出
- **逐条采纳或拒绝**，也可以全选/全不选
- 范围可选当前文件或全部标签页
- 规则集可保存复用（存在本地）
- 锁定的条目自动跳过

### 切分超长条目

针对「一句话字幕拖了很长、读起来来不及」的情况，把一条过长的字幕按标点和长度启发式地拆成多条，时间按各段字数比例分配（字多的那段占的时间长）。

- 入口：侧栏「校验」底部的按钮（带待处理条数），或「批量操作」里的「切分超长条目…」
- 口径可调：每行最多字数、每条最多行数、每段最短时长、是否优先在标点处断开
- **先预览再应用**：预览列出每条的原时间与原文（划掉）、切分后的每段时间与文本，可逐条勾选采纳或拒绝
- 时长不够切成两条时宁可不切；总时长只够切出更少段数时自动减少段数并标注
- 锁定的条目会被跳过；整次操作算一步，`Ctrl+Z` 可整体撤回

### 批量操作（侧栏「批量操作」标签）

时间平移、时间缩放、对齐到帧、消除微小空隙、合并过短条目、修复重叠、删除重复、删除空条目、重新编号、切分超长条目、去 SDH 标注、去内联标签。

### 校验

解析告警（序号缺失/重复、时间码异常、游离文本）+ 质检结果（重叠、负时长、空正文、超长行、时长过短/过长），点击可定位到对应条目。

### 格式支持

| 格式 | 扩展名 | 导入 | 导出 |
|------|--------|:---:|:---:|
| SubRip | `.srt` | ✅ | ✅ |
| WebVTT | `.vtt` | ✅ | ✅ |
| SubStation Alpha | `.ass` | ✅ | ✅ |
| SubStation Alpha v4 | `.ssa` | ✅ | ✅ |
| TTML / DFXP | `.ttml` `.dfxp` `.xml` | ✅ | ✅ |
| YouTube SBV | `.sbv` | ✅ | ✅ |
| LRC 歌词 | `.lrc` | ✅ | ✅ |
| MicroDVD | `.sub` | ✅ | ✅ |
| SAMI | `.smi` | ✅ | ✅ |
| JSON | `.json` | ✅ | ✅ |
| CSV | `.csv` | ✅ | ✅ |
| TSV | `.tsv` | ✅ | ✅ |
| 纯文本 | `.txt` | — | ✅ |

导出可选编码（UTF-8 / UTF-8 BOM / UTF-16 LE / GB18030 / BIG5）与换行（LF / CRLF），支持单文件下载或全部标签页打包 zip。MicroDVD 可单独指定帧率。

导入时若扩展名缺失或写错，会按文件内容自动识别格式。

### 其他

- **编码识别**：自动识别 UTF-8 / UTF-8 BOM / GB18030(GBK) / BIG5 / UTF-16 / Shift_JIS
- **自动保存**：工作区存在本地浏览器中，刷新或崩溃后可原样恢复（含未保存的修改）
- **PWA**：可安装，断网后仍能打开使用
- **亮暗主题**：跟随系统，可手动切换
- **隐私**：所有处理在本地完成，没有任何网络请求

## 快捷键

| 按键 | 作用 |
|------|------|
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Y` 或 `Ctrl/Cmd + Shift + Z` | 重做 |
| `Ctrl/Cmd + S` | 打开导出对话框 |
| `Ctrl/Cmd + H` | 打开批量替换面板 |
| `Ctrl/Cmd + Enter` | 在当前条目后新增一条 |
| `Delete` / `Backspace` | 删除选中条目 |
| `Alt + ↑ / ↓` | 上移 / 下移选中条目 |
| `↑ / ↓` | 在条目间移动选中 |
| `空格` | 播放 / 暂停（需先载入媒体） |
| `Esc` | 取消时间码编辑 |

时间轴：拖动块体平移、拖动两端调整起止、空白处按下定位播放头、双击块跳转到该条开始、`Ctrl/⌘ + 滚轮` 缩放。

表格：拖动表头分隔线调整列宽、双击分隔线恢复默认、工具栏「列设置」管理列的显隐与宽度。

媒体区：拖动与编辑区之间的分隔条调整高度比例、双击分隔条恢复默认比例。

## 已知限制

- 导出 GBK / BIG5 编码尚未支持（需要按需加载码表），界面里已标为「尚未支持」
- 导入 `.ssa` 再导出为 `.ssa` 会保留原始样式表；但从 `.ass` 导出为 `.ssa` 时，两种格式的样式字段定义不兼容，会回退到默认样式表
- CSV / TSV 里的换行用字面量 `\n` 转义（保证 Excel、WPS、pandas 都能正确读取），因此正文中原本的 `\n` 两个字符无法与换行区分
- 移动端只保证查看与轻编辑，拖拽交互需要桌面端
- 编码自动探测对 GB18030 与 BIG5 的区分依赖 `TextDecoder` 的严格模式，极少数文件可能误判；导出前可在状态栏核对
- 界面目前只有简体中文，i18n 尚未接入
